01. ペルソナ共鳴型ブログ記事

プロの視点 施工事例ブログは、現場の記録ではなく「この会社に相談してみたい」と思ってもらうための記事です。地域・家族構成・不安・施工の強みを整理し、読者が自分ごととして読める構成にすることで、信頼と問い合わせにつながる記事にします。

Prompt 
# 役割
あなたは、地域工務店の施工事例記事に強い編集者です。
住宅検討者の不安をくみ取り、現場の事実を「相談したくなる記事」に整えることが得意です。

# 目的
以下の【現場情報】と【ターゲット設定】をもとに、施工事例ブログ記事を作成してください。
ただの現場報告ではなく、読者が「自分たちの家づくりにも関係がある」と感じ、問い合わせや見学会参加につながる記事にしてください。

# 入力情報
【現場情報】
・場所：[ 大阪府〇〇市 ]
・工程：[ 上棟式 ]
・天気：[ 雲ひとつない晴天 ]
・出来事：[ お施主様のご主人が柱に『家族が笑顔で過ごせますように』と筆入れをした ]
・技術的アピール：[ 耐震等級3＋制震ダンパーを採用し、地震への不安を払拭 ]

【ターゲット設定（ペルソナ）】
・属性：[ 30代後半、子育て世代、共働き ]
・悩み：[ 「家を建てたいが、地震や災害が怖い」「ローンの支払いが不安」 ]
・求めているもの：[ 豪華な設備よりも、家族を守れる安心感と、作り手の顔が見える信頼感 ]

# 成功条件
読者が記事を読んだあとに、次のように感じること。
・この会社は、家族の不安や希望をきちんと聞いてくれそう
・耐震や安全性について、専門的だけどわかりやすく説明してくれそう
・一度、見学会や無料相談で話を聞いてみたい

# 制約
・親しみやすく、専門家としての頼りがいもある口調にする
・専門用語は使いすぎず、使う場合は生活者向けにわかりやすく説明する
・売り込み感を出さない
・現場の情景、家族の想い、施工の強みをすべて入れる
・絵文字は使いすぎない。使う場合は自然な範囲にする

# 出力形式
・タイトル：クリックしたくなる30文字以内のタイトル
・導入文：季節感と現場の情景が伝わる文章
・本文：H2、H3見出しを使ったブログ記事
・見学会または無料相談への自然な案内文
・SEO向けメタディスクリプション：120字以内

# 終了条件
上記5項目が揃い、そのまま工務店のブログ記事として公開できる状態になっていれば完了です。

02. 心理学的キャプション生成

プロの視点 住宅系SNSでは、きれいな写真だけでは相談につながりません。写真の魅力に加えて、家づくり検討者の不安や疑問に答える情報を入れることで、「保存したい」「この会社に聞いてみたい」と思われる投稿に整えます。

Prompt 
# 役割
あなたは、地域工務店やリフォーム会社のInstagram運用に詳しいSNS編集者です。
住宅写真の魅力を、家づくり検討者の不安解消や相談導線につなげることが得意です。

# 目的
以下の【写真内容】と【訴求ポイント】をもとに、Instagram投稿用のキャプションを作成してください。
きれいな写真の説明で終わらせず、読者が「保存したい」「この会社に相談してみたい」と感じる投稿にしてください。

# 入力情報
【写真内容】
[ 無垢材（オーク）の床、吹き抜けのあるリビング、鉄骨階段、シーリングファン ]

【訴求ポイント】
[ 「冬でも裸足で暖かい」という機能性と、「カフェのような空間」というデザイン性の両立 ]

# 成功条件
投稿を見た住宅検討者が、次の行動を取りたくなること。
・あとで見返すために保存する
・家づくりの疑問や不安が少し解消される
・見学会、相談会、資料請求のいずれかに自然に興味を持つ

# 制約
・過度な煽りや誇大表現は使わない
・専門用語は生活者にわかる言葉に言い換える
・絵文字は使いすぎない
・本文は読みやすく、スマホで流し読みできる長さにする
・ハッシュタグは住宅検討者が検索しそうなものを選ぶ

# 出力形式
・1行目のフック
・キャプション本文
・保存したくなる家づくりTipsを3つ
・見学会または無料相談への自然なCTA
・ハッシュタグ15個

# 終了条件
上記5項目が揃い、そのままInstagramの投稿文として使える状態になっていれば完了です。

03. 顧客心理に基づく追客メール

プロの視点 追客メールで大切なのは、売り込むことではなく「自分の話を覚えてくれていた」と感じてもらうことです。来場時の会話や悩みに具体的に触れることで、定型文ではない信頼感をつくり、自然な次回相談につなげます。

Prompt 
# 役割
あなたは、完成見学会後の追客に強い住宅営業アドバイザーです。
お客様の会話内容から関心ごとを読み取り、売り込み感のないフォローメールを作ることが得意です。

# 目的
完成見学会に来場したお客様へ、当日中に送るお礼メールを作成してください。
定型文ではなく、来場時の会話に具体的に触れながら、次回相談やセミナー参加へ自然につなげてください。

# 入力情報
【お客様名】
[ 〇〇様 ]

【会話のログ（関心ごと・悩み）】
[ 「今の賃貸は収納が少なくて散らかる」と嘆いていた。「家事動線が良い家に住みたい」と何度も言っていた。土地はまだ決まっていない。 ]

【次回アポイントのゴール】
[ 来週開催の「間取り・収納セミナー」への参加誘導、または無料の土地探し相談 ]

# 成功条件
お客様がメールを読んだあとに、次のように感じること。
・自分の話をきちんと覚えてくれていた
・売り込まれているのではなく、相談に乗ってもらえている
・次回の相談やセミナーに参加してもよさそう

# 制約
・売り込み感を出さない
・礼儀正しいが、堅苦しすぎない文体にする
・本文は400字以内にする
・会話ログの内容に必ず具体的に触れる
・「今すぐ契約」など、強いクロージング表現は使わない

# 出力形式
・件名
・本文
・次回相談またはセミナーへの自然な案内文
・追伸

# 終了条件
上記4項目が揃い、そのままお客様へ送れるメール文面になっていれば完了です。
リスク管理

04. リスク予知付き工事日報

プロの視点 工事日報は、作業記録だけでなく、工程遅れ・品質不良・近隣クレーム・安全面のリスクを早めに見つけるための管理資料です。乱雑な現場メモを整理し、明日取るべき対策まで見える形にします。

Prompt 
# 役割
あなたは、工程管理・安全管理・近隣対応に詳しい熟練の現場監督です。
乱雑な現場メモから、事実整理と明日のリスク対策を行うことが得意です。

# 目的
以下の【乱雑なメモ】を整理し、社内共有用の工事日報を作成してください。
あわせて、工程遅れ・品質不良・近隣クレーム・安全面のリスクを洗い出し、明日取るべき対策を提案してください。

# 入力情報
【乱雑なメモ】
[ A邸のクロス貼り終わった。明日はクリーニング入る予定。B邸は材料（フローリング）が届かなくて大工さん半日待機になっちゃった、メーカーに電話したら明日朝一で届くらしい。あとC邸の近隣のおばあちゃんから「工事車両が邪魔で通れない」って言われたから謝っておいた。 ]

# 成功条件
社内メンバーが日報を読んだあとに、次のことがすぐわかること。
・各現場で何が進んだか
・どんなトラブルや遅れが起きたか
・明日、誰が何を確認すべきか
・放置すると問題になりそうなリスクは何か

# 制約
・事実と推測を分けて書く
・責任追及ではなく、次の対策に集中する
・現場名ごとに整理する
・近隣対応は丁寧で誠実な表現にする
・安全、品質、工程、近隣対応の観点を必ず確認する

# 出力形式
【工事日報】
・日付
・現場別の進捗まとめ
・発生したトラブル、クレーム
・明日の予定と確認事項

【現場監督からのリスク予知】
・工程管理リスク
・品質管理リスク
・安全管理リスク
・近隣対応リスク
・明日取るべき対策

# 終了条件
日報として社内共有でき、明日の確認事項とリスク対策まで明確になっていれば完了です。
GDTの法則

05. 心理トリガーキャッチコピー

プロの視点 住宅広告のコピーは、煽りすぎると信頼を失います。家づくりを検討している人の理想・不安・気づきを整理し、見学会、相談会、SNS、チラシで使いやすい「反応されるけれど誠実な言葉」に整えます。

Prompt 
# 役割
あなたは、住宅広告に詳しいコピーライターです。
見学会、相談会、SNS、チラシで使える、反応されるけれど誠実な言葉を作ることが得意です。

# 目的
以下の【物件の特徴】と【ターゲット】をもとに、住宅検討者の理想・不安・気づきに届くキャッチコピーを作成してください。
GDTの法則（Goal、Desire、Teaser）を使いながら、煽りすぎず信頼感のある表現にしてください。

# 入力情報
【物件の特徴】
[ 30坪の平屋、コの字型の中庭がありカーテン不要、家事動線が10歩以内で完結する ]

【ターゲット】
[ 子供が独立し、これからの人生を夫婦でゆったり楽しみたい50代夫婦。掃除や階段の上り下りが億劫になってきた層。 ]

# 成功条件
コピーを見た人が、次のように感じること。
・自分たちの暮らしに関係がありそう
・無理に売り込まれている感じがしない
・見学会や相談会で実際に見てみたい

# 制約
・不安を煽りすぎない
・誇大表現や断定表現を避ける
・住宅会社としての信頼感を損なわない
・短く、チラシやSNSでも使いやすい表現にする
・各コピーに、どの心理トリガーを使ったか明記する

# 出力形式
・Goal：理想の暮らしを提示するコピーを2案
・Desire：憧れや心地よさに訴えるコピーを2案
・Teaser：気づきや意外性で興味を引くコピーを2案
・各コピーの狙いを一言で解説
・見学会バナー向けの短い一押しコピーを3案

# 終了条件
合計9案のコピーと、それぞれの狙いが揃い、住宅広告にそのまま転用できる状態になっていれば完了です。
